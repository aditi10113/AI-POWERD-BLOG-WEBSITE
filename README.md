# 🚀 QuickBlog – AI-Powered Full-Stack Blog Platform

QuickBlog is a modern full-stack blogging platform built with **React.js, Node.js, Express.js, MongoDB, Tailwind CSS, and Google Gemini AI**.

The platform allows users to explore and read blogs, while administrators can create, manage, and delete blog posts through a dedicated dashboard. AI integration helps generate blog content efficiently.

---

## ✨ Features

### 👤 User Features
- Browse all published blogs
- Search and explore blog content
- Read individual blog posts
- View blog categories
- Responsive and modern UI
- Smooth navigation
- Comment functionality

### 🔐 Admin Features
- Secure admin authentication
- JWT-based authentication
- Admin dashboard
- Create new blog posts
- Edit and manage blog content
- Delete blog posts
- Manage comments
- Upload blog images

### 🤖 AI Features
- AI-powered blog content generation
- Google Gemini API integration
- Generate content quickly using AI
- Markdown-based content rendering

### 🎨 UI & UX
- Responsive design
- Tailwind CSS styling
- Modern dashboard
- Rich text editor using Quill
- Toast notifications
- Smooth animations
